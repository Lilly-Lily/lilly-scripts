# 명조 Engine.ini 관리 도구

Wuthering Waves Engine.ini Manager

명조(Wuthering Waves) 클라이언트의 `Engine.ini`를 한곳에서 관리하는 PowerShell GUI 도구임.

Kuro, Google, Steam, Epic 클라이언트를 최대 4개까지 등록함. 작업마다 대상 클라이언트를 체크박스로 골라 백업·삭제·이식·복원을 선택적으로 수행함.

> [!WARNING]
> 게임 설정 파일을 덮어쓰거나 삭제하는 도구임. 사용 전에 [면책 조항](#면책-조항)을 확인할 것.

## 주요 기능

- 클라이언트별 경로 지정. 경로 상태(●) 표시와 `Engine.ini` 폴더 바로 열기를 지원함.
- **백업**: 클라이언트명과 일시를 붙여 `Backup` 폴더에 누적 보관함.
- **삭제**: 휴지통으로 이동함. 삭제 전에 백업할지 고를 수 있음.
- **이식**: 커스텀 `Engine.ini`를 선택한 클라이언트에 적용함. 이식 전에 백업할지 고를 수 있음.
- **복원**: 아래 기능을 지원함.
  - 백업 목록 표시. 클라이언트별 필터와 최신순 정렬을 지원함.
  - 선택한 백업의 내용 미리보기
  - 교차 복원: 한 클라이언트의 백업을 다른 클라이언트에도 적용함.
  - 불필요한 백업 삭제
- 커스텀 설정 배포처인 [AlteriaX/WuWa-Configs](https://github.com/AlteriaX/WuWa-Configs) 페이지 바로 열기. 다운로드는 사용자가 직접 함.
- 설정한 경로는 `setting.json`에 저장되어 다음 실행 때도 유지됨.

## 요구 사항

- Windows 10 / 11
- Windows PowerShell 5.1 (Windows 기본 포함)
- 관리자 권한은 필요 없음. 단, 게임을 `C:\Program Files` 등 보호된 폴더에 설치했다면 필요할 수 있음.

## 사용법

1. `WuWaIniManager.bat`과 `WuWaIniManager.ps1`을 같은 폴더에 둠.
2. 인터넷에서 받은 경우 `.ps1` 파일 우클릭 → **속성** → **차단 해제**를 체크하고 확인을 누름.
3. `WuWaIniManager.bat`을 더블클릭해서 실행함.
4. 각 클라이언트의 [찾기]로 `Wuthering Waves.exe`가 있는 폴더를 지정함.
5. 대상 체크박스를 고르고 원하는 작업 버튼을 누름.

## 구성 파일

| 파일 | 역할 |
| --- | --- |
| `WuWaIniManager.bat` | 실행 정책을 우회(`-ExecutionPolicy Bypass`)하고, 콘솔 창을 숨긴 채 `.ps1`을 실행하는 런처 |
| `WuWaIniManager.ps1` | 창(UI), 경로 확인, 백업·삭제·이식·복원, 로그 표시를 모두 담당하는 본체 |
| `setting.json` | 클라이언트 경로 4개와 커스텀 ini 경로. 실행 시 자동 생성 |
| `Backup/` | 백업 파일 보관 폴더. 첫 백업 시 자동 생성 |

`setting.json`과 `Backup/`은 개인 환경 파일이라 저장소에 포함하지 않음.

## 실행 흐름

1. `.bat`이 `.ps1`을 실행함. 실행하면서 고해상도(DPI) 배율을 읽어 창 크기를 맞춤.
2. `setting.json`에서 이전 경로를 불러오고, 클라이언트별 상태를 확인함.
3. 작업 버튼을 누르면 체크된 클라이언트에만 작업을 수행함.
4. 삭제·이식·복원은 아래 순서로 진행함.
   1. 게임이 실행 중인지 확인함.
   2. 백업할지 물어봄.
   3. 작업을 실행함.
5. 결과는 아래쪽 로그 창에 클라이언트별로 기록됨.

## 경로와 상태 표시

지정 경로는 `Wuthering Waves.exe`가 있는 폴더 기준이며, `Engine.ini`는 아래 위치에서 찾음.

```
[지정 폴더]\Client\Saved\Config\WindowsNoEditor\Engine.ini
```

| 상태(●) | 의미 | 대상 체크박스 |
| --- | --- | --- |
| 초록 | 경로 정상, `Engine.ini` 있음 | 사용 가능 |
| 주황 | 경로 정상, `Engine.ini` 없음 | 사용 가능 |
| 빨강 | 지정 폴더에 `Wuthering Waves.exe`가 없음 | 비활성 |
| 회색 | 경로 미설정 | 비활성 |

## 백업 파일 이름

백업 파일 이름은 `Engine_<클라이언트>_<yyyyMMdd>_<HHmmss>.ini` 형식임. 예) `Engine_Kuro_20261101_052700.ini`

같은 초에 같은 클라이언트의 백업이 또 생기면 끝에 `_2`, `_3` … 을 붙여서 덮어쓰지 않음. 복원 창은 이 형식의 파일만 목록에 표시하므로 파일명은 바꾸지 말 것.

## 로그

| 로그 | 의미 | 대응 |
| --- | --- | --- |
| `[클라이언트] 백업 완료` / `이식 완료` / `복원 완료` | 정상 처리 | 없음 |
| `[클라이언트] Engine.ini 없음, 건너뜀` | 백업·삭제할 파일이 없음 | 게임을 한 번 실행하면 생성됨 |
| `[클라이언트] 경로 오류, 건너뜀` | 지정 폴더에 `Wuthering Waves.exe`가 없음 | 경로 다시 지정 |
| `[클라이언트] ~ 실패` | 해당 클라이언트만 실패. 나머지는 계속 진행 | 뒤에 붙은 이유 확인. 파일 사용 중이거나 권한 문제일 수 있음 |
| `~ 취소` | 확인 창에서 [취소]를 누름 | 없음 |

## 사용 시점과 주의할 점

- 커스텀 `Engine.ini`를 적용하거나 바꿔볼 때, 게임 업데이트 전에 현재 설정을 보관해둘 때 쓰면 됨.
- 삭제·이식·복원은 게임을 끄고 진행할 것. 실행 중에는 변경이 반영되지 않거나 게임이 파일을 덮어쓸 수 있음.
- `Engine.ini`에 읽기 전용 속성은 걸지 않음.
- 프로그램 폴더를 옮길 때는 `setting.json`과 `Backup/`도 함께 옮겨야 설정과 백업이 유지됨.
- 경로의 `\`가 `₩`로 보이는 것은 한글 글꼴의 표시 방식이며 실제 경로에는 문제없음.
- `.ps1`을 수정할 때는 인코딩을 UTF-8(BOM)으로 유지할 것. BOM이 없으면 PowerShell 5.1에서 한글이 깨져서 실행되지 않음.

## 면책 조항

- 이 도구는 개인이 만든 비공식 도구이며, Kuro Games 및 명조(Wuthering Waves)와 관련이 없음. 게임 이름과 상표는 각 소유자의 것임.
- 이 도구는 지정한 클라이언트의 `Client\Saved\Config\WindowsNoEditor\Engine.ini`와 프로그램 폴더의 `Backup/`, `setting.json`만 생성·수정·삭제함. 게임 실행 파일과 그 밖의 게임 데이터는 건드리지 않음.
- 삭제는 휴지통으로 이동하는 방식이지만, 이식·복원은 기존 `Engine.ini`를 덮어씀. 필요하면 백업 후 진행할 것.
- 커스텀 `Engine.ini`의 내용과 그 효과는 해당 파일 제공자의 책임이며, 이 도구는 파일을 복사만 함.
- 이 도구의 사용으로 생기는 데이터 손실, 게임 문제, 계정 관련 불이익 등 어떠한 결과에 대해서도 작성자는 책임지지 않음. 사용에 따른 책임은 사용자에게 있음.
