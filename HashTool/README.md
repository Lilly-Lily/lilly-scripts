# 해시 도구 (HashTool)

파일·폴더의 해시 값을 조회·저장·비교·검증하는 Windows용 GUI 도구.

파일·폴더의 SHA256 등 해시 값을 계산해 JSON(검증용)이나 CSV(보기용)로 저장함. 여러 파일·폴더가 서로 같은지 비교하고, 저장해 둔 기록이나 다운로드 페이지에 공개된 해시 값과 지금 파일을 대조해 검증할 수 있음.

> [!WARNING]
> 개인이 만든 비공식 도구임. 사용 전에 [면책 조항](#면책-조항)을 확인할 것.

## 주요 기능

- 파일과 폴더 모두 지원. 폴더는 대표 해시 값 하나와 파일별 해시 목록을 함께 보여줌
- 결과를 JSON(검증용 기록)과 CSV(엑셀 보기용)로 저장
- 원본 묶음과 대상 묶음 비교: 이름 기준 또는 내용 기준(이름 무시)
- 여러 대상과 비교: 대상을 폴더별 비교군으로 자동으로 나눠 각각 원본과 비교
- 저장된 JSON 기록과 현재 상태 대조 (다른 위치와도 가능)
- 공개된 해시 값을 붙여 넣어 대조. 알고리즘은 길이로 자동 판별
- SHA256, SHA1, SHA384, SHA512, MD5 지원, 하위 폴더 포함 여부·제외 패턴 지정
- 백그라운드 계산, 진행률 표시와 취소 가능
- 창이나 `.bat` 아이콘에 끌어다 놓기로 대상 추가

## 요구 사항

- Windows 10 / 11
- Windows PowerShell 5.1 (Windows 기본 포함, 추가 설치 없음)
- 관리자 권한 필요 없음

## 사용법

1. 저장소에서 `hash-tool` 폴더의 파일을 내려받아 한 폴더에 둠.
2. 인터넷에서 받은 파일이라 실행이 막히면 `HashTool.ps1` 우클릭 → 속성 → **차단 해제** 체크 → 확인.
3. `HashTool.bat`을 더블클릭해서 실행함.
4. 탭을 고르고 목록에 파일·폴더를 끌어다 놓은 뒤 [▶ 계산] / [▶ 비교] / [▶ 검증]을 누름.

`HashTool.bat` 아이콘 위에 끌어다 놓으면 해당 항목이 들어간 상태로 열림.

| 끌어다 놓은 항목 | 열리는 탭 |
| --- | --- |
| `.json` 파일 1개 | 검증 탭 (기록 파일로 지정) |
| 2개 | 비교 탭 (첫 번째는 원본, 두 번째는 대상) |
| 그 외 (1개 또는 3개 이상) | 조회·저장 탭 |

## 구성 파일

| 파일 | 역할 |
| --- | --- |
| `HashTool.bat` | 실행 정책을 우회(`-ExecutionPolicy Bypass`)하고, 콘솔 창을 숨긴 채 `.ps1`을 실행하는 런처 |
| `HashTool.ps1` | 창(UI), 해시 계산, 저장, 비교, 검증을 모두 담당하는 본체 |

설정 파일은 만들지 않음. 사용 중 저장한 JSON·CSV는 개인 경로가 들어 있으므로 저장소에 포함하지 않음(`.gitignore`).

## 동작 원리

1. 대상 목록의 파일·폴더를 확인하고, 폴더는 하위 파일 목록을 만듦(제외 패턴 적용).
2. 별도 실행 공간(runspace)에서 파일을 4MB 단위로 읽으며 해시를 계산함. 이 동안 창은 멈추지 않고 진행률을 표시함.
3. 폴더는 안의 모든 파일의 '상대 경로 + 해시' 목록을 정렬해서 다시 해시한 값을 대표 해시로 씀.
4. 탭에 따라 결과를 표시·저장하거나, 짝을 맞춰 비교·검증함.

폴더 해시의 특징:

- 파일 내용, 파일 이름, 폴더 구조 중 하나라도 바뀌면 값이 달라짐.
- 빈 폴더, 수정 날짜 등 메타데이터와 폴더 이름 자체는 포함하지 않음.
- 이 도구만의 계산 방식이라 다른 프로그램의 폴더 해시와는 비교할 수 없음.

## 탭별 기능

### 조회·저장

| 버튼 | 동작 |
| --- | --- |
| + 파일 / + 폴더 | 선택 창으로 대상 추가 |
| 선택 삭제 / 비우기 | 목록에서 빼기 (`Delete` 키도 가능) |
| 해시 복사 | 선택한 결과의 해시를 클립보드로 복사 |
| 파일별 목록 | 폴더 안 파일별 해시 창 (결과 더블클릭도 가능, 검색·CSV 저장 지원) |
| JSON 저장 | 검증 탭에서 쓸 기록으로 저장. 알고리즘·하위 폴더·제외 패턴 설정도 함께 저장됨 |
| CSV 저장 | 엑셀 보기용으로 저장. 검증에는 쓸 수 없음 |

### 비교

원본 목록과 대상 목록을 각각 하나의 묶음으로 보고 비교함. 기본은 이름 기준으로, 파일은 파일 이름, 폴더는 폴더 안 상대 경로로 짝을 지음.

| 옵션 | 동작 |
| --- | --- |
| 내용 기준 (이름 무시) | 해시가 같은 파일끼리 짝을 지음. 예) `setup(1).exe`와 `setup.exe` |
| 여러 대상과 비교 | 대상 목록의 폴더는 각각, 파일은 같은 상위 폴더끼리 묶어 비교군을 만들고 각각 원본과 비교 |

| 상태 | 의미 |
| --- | --- |
| 일치 | 원본과 대상의 해시가 같음 |
| 내용 다름 | 같은 이름이지만 해시가 다름 |
| 원본에만 | 원본에만 있고 대상에는 짝이 없음 |
| 대상에만 | 대상에만 있고 원본에는 짝이 없음 |
| 읽기 오류 | 파일을 읽지 못해 비교할 수 없음 |

비교군은 모든 항목이 '일치'일 때만 '동일'로 판정함.

### 검증

| 방식 | 동작 |
| --- | --- |
| 저장된 기록(JSON)과 비교 | 기록에 저장된 원래 경로(또는 '다른 위치와 비교'로 지정한 경로)를 다시 계산해 대조. 저장 당시 설정을 그대로 사용 |
| 해시 값 직접 입력 | 붙여 넣은 해시와 대상 파일의 계산값을 대조. 길이로 알고리즘 판별(MD5 32자, SHA1 40자, SHA256 64자, SHA384 96자, SHA512 128자) |

JSON 검증의 차이 상태는 `내용 다름` / `삭제됨` / `추가됨` / `읽기 오류`로 표시함.

## 사용 시점과 주의할 점

- 다운로드한 파일이 공개된 해시와 같은지, 백업본이 원본과 같은지, 게임 업데이트·모드 설치 뒤 어떤 파일이 바뀌었는지 확인할 때 씀.
- 관리자 권한으로 실행하면 Windows 보안 정책상 탐색기에서 끌어다 놓기가 막힘. 일반 실행을 권장함.
- 권한이 없거나 다른 프로그램이 잠근 파일은 '읽기 오류'로 표시되고 나머지는 계속 계산함.
- 게임 실행 중에는 파일이 바뀌거나 잠길 수 있으므로 게임을 끄고 계산하는 것이 정확함.
- JSON 기록 파일을 직접 수정하면 검증 결과가 틀어질 수 있으므로 그대로 둘 것.
- 경로의 `\`가 `₩`로 보이는 것은 한글 글꼴의 표시 방식이며 실제 경로에는 문제없음.
- `.ps1`을 수정할 때는 인코딩을 UTF-8(BOM)으로 유지할 것. BOM이 없으면 Windows PowerShell 5.1에서 한글이 깨져 실행되지 않음.

## 면책 조항

- 이 도구는 개인이 만든 비공식 도구이며, 특정 게임사나 소프트웨어 회사와 관련이 없음. 언급된 게임 이름과 상표는 각 소유자의 것임.
- 이 도구는 대상 파일을 읽기만 하며, 수정·삭제·이동하지 않음. 파일을 쓰는 경우는 사용자가 지정한 위치에 JSON·CSV 결과를 저장할 때뿐임.
- 실행 전에 스크립트 내용을 직접 확인할 것을 권장함.
- 해시 비교 결과는 파일 내용의 동일성만 판단하며, 파일의 안전성(악성 여부)을 보증하지 않음.
- 이 도구의 사용으로 생기는 데이터 손실, 게임 문제, 계정 관련 불이익 등 어떠한 결과에 대해서도 작성자는 책임지지 않음. 사용에 따른 책임은 사용자에게 있음.
