# 명조 이미지 간편수정

Wuthering Waves Image Quick Edit

명조(Wuthering Waves) 스크린샷의 UID를 자동으로 가리는 Windows용 도구임.

크롭, 리사이즈, 포맷 변환까지 한 번에 처리할 수 있음. 여러 장이나 폴더째로 드롭해도 한꺼번에 처리하고, 원본 파일은 건드리지 않음.

> [!WARNING]
> 개인이 만든 비공식 도구임. 사용 전에 [면책 조항](#면책-조항)을 확인할 것.

## 주요 기능

- 드롭 창에 이미지 여러 장 또는 폴더를 던지면 일괄 처리
- UID 자동 가리기 (블러 / 모자이크 / 단색 덮기)
- 화면 종류 자동 판별: PC 일반 화면, 휴대폰 화면, 시네마틱(상하 검은 띠) 화면
- 해상도와 화면 비율이 달라도 UI 크기 배율에 맞춰 UID 위치를 계산
- 크롭(시네마틱 검은 띠 제거 / 비율 직접 지정), 리사이즈(가로 px 기준), 포맷 변환(PNG / JPG)
- 이전 작업 설정을 저장해 두고 다음에 그대로 재사용
- 결과 파일명 끝에 작업 일시를 붙여 기존 파일을 덮어쓰지 않음
- 저장 위치 지정 (기본: 원본 폴더 안 `masked`)

## 요구 사항

- Windows 10 / 11
- Windows PowerShell 5.1 (Windows에 기본 포함)
- 추가 설치 없음, 관리자 권한 필요 없음

## 사용법

1. 이 폴더를 통째로 내려받아 원하는 위치에 둠. `WWImageQuickEdit.bat`과 `WWImageQuickEdit.ps1`은 반드시 같은 폴더에 있어야 함.
2. 인터넷에서 받은 경우 두 파일 각각 **오른쪽 클릭 → 속성 → 하단 '차단 해제' 체크 → 확인**.
3. `WWImageQuickEdit.bat`을 더블클릭하면 드롭 창이 뜸.
4. 이미지 여러 장이나 폴더를 드롭 영역에 끌어다 놓음.
5. [① 이전 설정 그대로] 또는 [② 새로 설정]을 고름. 처음 실행하면 바로 설정 창이 뜸.
6. 처리가 끝나면 [결과 폴더 열기]로 결과를 확인함.

`WWImageQuickEdit.bat` 아이콘 위에 직접 드롭하면 창 없이 마지막 설정으로 바로 처리하고, 결과는 콘솔 창에 표시함.

## 구성 파일

| 파일 | 역할 |
| --- | --- |
| `WWImageQuickEdit.bat` | 실행 정책을 우회(`-ExecutionPolicy Bypass`)하고, 콘솔 창을 숨긴 채 `.ps1`을 실행하는 런처 |
| `WWImageQuickEdit.ps1` | 창(UI), 화면 판별, 이미지 처리, 로그 표시를 모두 담당하는 본체 |
| `settings.json` | 마지막으로 실행한 작업 설정. 실행할 때마다 자동 저장 |
| `error.log` | 프로그램 오류가 났을 때만 생김. 마지막 오류 내용을 기록 |

`settings.json`과 `error.log`는 실행 중 자동으로 생기는 개인 환경 파일이라 저장소에 포함하지 않음.

## 실행 흐름

1. **준비**: `.ps1` 안의 C# 이미지 처리 엔진을 컴파일하고, 고해상도(DPI) 대응을 켬. 창이 뜨기까지 1~2초 걸림.
2. **드롭 대기**: 창을 닫기 전까지 계속 드롭할 수 있음.
3. **작업 선택**: 이전 설정이 있으면 내용을 보여주고 그대로 쓸지, 새로 설정할지 물어봄.
4. **처리**: 파일마다 화면 판별 → UID 가리기 → 크롭 → 리사이즈 → 저장 순서로 진행하고, 한 줄씩 로그 창에 기록함.
5. **요약**: 마지막에 `완료: 성공/전체장`을 출력함.

## 화면 판별과 UID 위치

UI 크기 배율을 `min(가로/3840, 세로/2160)`로 계산하고, 오른쪽·아래 가장자리 기준으로 UID 위치를 잡음.

| 판별 결과 | 조건 | 가리는 위치 |
| --- | --- | --- |
| 일반 | 가로/세로 비율 1.70~1.85 (PC 16:9) | 맨 오른쪽 아래 |
| 휴대폰 | 그 외 비율 (폴드 안쪽·바깥 화면 등) | 오른쪽 아래, PC보다 안쪽 |
| 시네마틱 | 위아래 가장자리가 검은 띠 | 아래쪽 검은 띠 바로 위 오른쪽 |

## 작업 설정

| 항목 | 선택지 | 비고 |
| --- | --- | --- |
| UID 가리기 | 블러 / 모자이크 / 단색 덮기 | 확실히 가리려면 단색 덮기가 가장 안전 |
| 크롭 | 안 함 / 시네마틱 검은 띠 제거 / 직접 지정 | 띠 제거는 시네마틱 화면에만 적용. 직접 지정은 0~1 비율 |
| 리사이즈 | 사용 시 가로 px 지정 | 비율 유지. 원본보다 크게 확대하지는 않음 |
| 저장 포맷 | 원본 유지 / PNG / JPG | JPG 품질 95 |
| 저장 위치 | 기본: 원본 폴더 안 `masked` / 직접 지정 | 지정한 폴더가 없으면 자동으로 만듦 |

## 저장과 결과 판정

결과 파일명 끝에 작업 일시가 붙음. 예) `스샷.jpg` → `스샷_20261101-050100.jpg`. 같은 초에 같은 이름이 또 나오면 `_2`, `_3`을 덧붙임.

| 로그 | 의미 | 대응 |
| --- | --- | --- |
| `[n/N] OK` | 정상 처리 후 저장 | 없음 |
| `[n/N] 실패` | 해당 파일만 처리 못 함. 나머지는 계속 진행 | 뒤에 붙은 이유 확인. 파일 손상이나 다른 프로그램 사용 중일 수 있음 |
| `처리할 이미지가 없습니다` | 지원하지 않는 형식만 드롭함 | png, jpg, jpeg, bmp만 지원 |
| 오류 창 | 프로그램 자체 오류 | 같은 폴더의 `error.log` 확인 |

## 사용 시점과 주의할 점

- WebP 등 png, jpg, jpeg, bmp 외 형식은 읽지 못함.
- 휴대폰 시네마틱 화면은 실제 샘플로 검증하지 않았음.
- UID 위치를 확인하려면 `WWImageQuickEdit.ps1` 상단의 `$Preview`를 `$true`로 바꿈. 가리지 않고 빨간 박스만 그림.
- 고정 설정(UID 위치, 블러 강도, 모자이크 크기, 단색 색상, 파일명 일시 추가 여부 등)은 `WWImageQuickEdit.ps1` 상단의 '고정 설정' 부분에서 고침.
- `WWImageQuickEdit.ps1`을 수정할 때는 인코딩을 **UTF-8(BOM)** 으로 유지할 것. BOM이 없으면 PowerShell 5.1이 한글을 잘못 읽어 실행되지 않음.

## 면책 조항

- 이 도구는 개인이 만든 비공식 도구이며, Kuro Games 및 명조(Wuthering Waves)와 관련이 없음. 게임 이름과 상표는 각 소유자의 것임.
- 이 도구는 사용자가 드롭한 이미지 파일을 읽어 새 파일로 저장할 뿐이며, 원본 이미지나 게임 파일, 게임 클라이언트는 수정하지 않음.
- UID 가리기는 미리 정한 위치를 기준으로 동작하므로, 게임 UI 변경이나 특수한 화면에서는 UID가 완전히 가려지지 않을 수 있음. 결과물을 공유하기 전에 직접 확인할 것.
- 이 도구의 사용으로 생기는 데이터 손실, 정보 노출, 게임 문제, 계정 관련 불이익 등 어떠한 결과에 대해서도 작성자는 책임지지 않음. 사용에 따른 책임은 사용자에게 있음.
